# Baruipur Random Forest Land Cover Classification

## Overview

This project presents a land cover classification of **Baruipur, West Bengal, India**, using **Google Earth Engine (GEE), Random Forest machine learning, SQL, and QGIS**.

The objective was to classify the study area into five major land cover classes and produce a professional final map using QGIS.

## Land Cover Classes

- Water
- Built-up
- Vegetation
- Crop
- Bare soil

## Workflow

**Google Earth Engine → Random Forest Classification → SQL Analysis → QGIS Visualization & Cartography**

### 1. Google Earth Engine
Satellite imagery was processed in Google Earth Engine and used as the basis for supervised Random Forest land cover classification.

### 2. Random Forest Classification
A Random Forest classifier was used to classify the study area into five land cover categories.

### 3. SQL Analysis
SQL was used as part of the training-sample/data analysis workflow to support the classification process.

### 4. QGIS
The classified raster was brought into QGIS for visualization, layer management, cartographic design, and final map production.

## Project Outputs

### QGIS Project
The `QGIS_Project` folder contains the QGIS project file used for the analysis and final map preparation.

### Output Maps
The `Output_Maps` folder contains the final land cover classification map in PNG and PDF formats.

### Final Classification Raster
The `Final_Classification_Raster` folder contains the final Random Forest classification raster.

## Final Result

The final output provides a spatial representation of the distribution of water, built-up areas, vegetation, cropland, and bare soil across the Baruipur study area.
